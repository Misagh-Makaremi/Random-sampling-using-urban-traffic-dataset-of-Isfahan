# Random-sampling-using-urban-traffic-dataset-of-Isfahan
### Final project for lesson Sampling1. Statistical random sampling for SRSWOR, SRSWR, PPSWR using R Package "dplyr".

In order to carry out this project, the data provided regarding urban traffic in Isfahan was used. In this file, 350 rows are introduced as 350 city streets, which are provided to us in three columns of information for each. The first column (Domain) indicates the city block area, which is coded from 1 to 7. The second column (X) indicates the number of people living on that street. The third column (Y) also indicates how long it will take for cars entering this street to travel this route between 7 and 7:15.
Therefore, we intend to implement the different sampling methods mentioned below, and select a random sample of the specified size from the existing population of 350 and provide an appropriate estimate for the mean, variance, and confidence interval of the travel time on these streets.
